## 3. Stage B —— 可执行解题计划（ReasoningPlanner）

- `StructuredPlan`：题型假设 / givens（值+题干 span+单位）/ steps（var, expr, source,
  deps）/ target / unknowns；`solver_source` 全程标注（rules | word_problem | llm_planner）。
- `execute_plan`：Fraction 精确递归下降求值（含空格 token 修复）。
- `validate_plan`（B1 依赖图）：span 逐字回查题干、数值必须是 span 原文的等价类
  （n、n/100、1±n/100…）、标识符绑定、无重复定义；不可满足即拒。
- 双路径 + 多计划（B2）：确定性通道优先；退化仲裁——直接抽取表达式若为**原样换算**
  且题干含变化过程（`_degenerate_percent`），判为伪计划交还建模层，建模层无产出再回退
  原结果交 verify 把关。
- 修正回路：plan_llm 对协议失败（空/坏 JSON）与校验缺陷各带一次结构化反馈重试；
  `feedback=` 支持 stale-target 诊断（目标值==原始给定值而题干有变化 → 反馈重规划）。
- LLM 输入永不含金标；"我认为答案是 A"式输出被结构协议杜绝。

## 4. Stage C —— 三域落地

### C1 数字计算

nc-03（稀释伪计划 → 建模 correct_accept）。

### C2 资料分析（R5 最大缺口）
- `tools/text_material.py`：中文文字/表格混合材料 → **统一事实表**（两行表头约定），
  与图片表格走同一 `normalize_table → data_plan` 路径。
- `data_plan` 扩展：基期值（跨年邻列回退）、增长量（率证据 `O1*O2/(1+O2)` 与两期差式）、
  占比（"占…的"冒号形）、时间行标签排除、"全年/累计"总计列识别。
- dev da-11/12/13 全对且 verify accept；**R5 全量中 xn-da-04 由 None 变为 B 正确接受**
  （来自"全年"总计识别的通用化，非按题调参；路径 360÷1320=27.27% 独立复核成立）。

### C3 判断推理
- `tools/prop_logic.py`：公式小语言（`! & | => <=>`）+ 中文方向规则
  （如果/只要→前推后；只有…才→后推前；除非…否则；所有…都；并非）+ Z3 判定。
  原则性防线：**特称量化句（"有些A是B"）超出命题逻辑表达力 → 如实拒绝**（不得归并成
  事实 atom）；实质蕴含**空真防线**（前件与前提不相容、或后件已是前提定理 → 不计命中）；
  元选项（"无法确定…"）不判定。
- LLM 只做**子句抽取**（text 必须逐字命中题干，formula 骨架），求值全在本地 Z3；
  verify 从 meta 重建公式独立重放（不共享求解期结论），来源回查域=题干+选项。
- dev lg-14（所有→逆否）/lg-15（只有…才→肯定后件）solve+verify accept；
  **R5 xn-xl-07 由 None → A 正确接受**；xn-xl-08（特称三段论）**维持诚实拒答**——
  首版实验曾误放行（空真+量化归并），两条原则性防线修复后回归为 0 false_accept。
- 数列：素数序列、分子分母复合（1/2,3/4,5/8,7/16→9/32）零 API；
  **R5 xn-ns-07/xn-ns-12 由 None → 正确接受**。

### 言语理解（§4 规则 5/6）
- LLM 证据协议改为**逐字文本自动定位**（模型给的字符索引最易出错，绑定纪律不变：
  定位不到=无效证据）；insufficient/self_consistent + 证据全部逐字 + 竞争项全排除
  → 允许释放（保守拒答不再是能力替代品）；refuted 仍阻断；无证据仍拒。
- dev vu-22（主旨覆盖）/vu-23（成语搭配）correct_accept；R5 规则通道零 API 行为不变。
