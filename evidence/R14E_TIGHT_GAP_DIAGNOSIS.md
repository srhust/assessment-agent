# R14 tight 排版覆盖缺口：逐页成因（零 API、零规则改动）

脚本 `scripts/e2e_r14_tight_gap_diagnosis.py` → `R14E_TIGHT_GAP_DIAGNOSIS.json`。
对象：7 张 `--tight` 页（6 扰动变体 + 1 真实截图 tight）+ 4 张真实截图对照页。
本页**只做测量**：不调阈值、不加规则、不改 `src`；页名来自语料目录，
所有数字由页面像素与生产链路自报 note 导出。**是否要覆盖这些排版，由人工裁决
（STOPGATE 裁决点 5）**。

## 0. 先更正一处我自己的口径错误（V2 → V3）

`R14E_NEWLAYOUT_REGRESSION_V2` 的 tight 汇总把 **Solver 证据链单元数**标成
"消费单元"，与**落盘裁剪份数**混同，使我此前"4 页选项 0 份"的表述**过强**。
`R14E_NEWLAYOUT_REGRESSION_V3` 已把两个量分列（其余数字一字未变：层计数
16/7/7、`wrong_releases []`、`checks_failed []`、`band20_flagged []`）：

| tight 页 | 声明 | 落盘裁剪 | 证据链单元 | 更正后的说法 |
|---|---|---|---|---|
| ft-mirror-04--tight（真实截图） | 0 | 3 | 3 | 证据完整（行序无字母路径） |
| ft-mirror-04--tight（扰动母版同名） | 3 | 3 | 3 | 证据完整 |
| ft-rot90-01--tight | 4 | 4 | 4 | 证据完整 |
| **ft-grid-10--tight** | 4 | **4** | 0 | 裁剪已写盘，但未进证据链 |
| **ft-overlay-13--tight** | 4 | **4** | 0 | 同上 |
| **ft-scale-09--tight** | 3 | **0** | 0 | 确为 0 份 |
| **ft-trans-07--tight** | 3 | **0** | 0 | 确为 0 份 |

所以缺口的真实构成是：**2 页根本拿不到选项裁剪 + 2 页拿到裁剪但那次运行随后
在题干侧弃权（且裁剪含并图）**。两者都**没有**被释放（零错放不变），
但把它们一律说成"选项 0 份"是不准确的——我在此更正。

## 1. 四类成因（逐页实测）

### A 类 · 选项带未定位 —— `ft-scale-09--tight`
末带 `[157,190]` 的列段实测 **3 段、尺寸悬殊**：
`w36×h33 ink 378` ｜ `w11×h10 ink 38` ｜ `w24×h22 ink 168`（实心度均 ≈0.32）。
`localize_page(n=3)` → `notes=['options_band_not_detected']`、0 单元。
行序候选谓词在 `cand_n=2` 因 `ink_uniform` 不过（378 vs 38）；`cand_n=4` 因
`same_row / pitch / width / height / ink` 全不过。字母层实测只有 `{h=10: 1 个}`，
不足以构成 3 个锚点。
**这是尺度序列的本质**：三选项**故意**大小不同，"等距 + 宽高一致 + 墨一致"
的正则性谓词**按设计必须**拒绝它——放松它等于拆掉防假格阵的那道门。

### B 类 · 单元定位到但裁剪完整性未过 —— `ft-trans-07--tight`
末带 `[164,184]` 三段实测 `w20×h8 ink160` ｜ `w20×h8 ink160` ｜
`w8×h20 ink160`（**实心度都是 1.0**，即真图形就是横条/竖条）。
三单元都在，但第三格宽 8px → `min(h,w)=8 < MIN_CELL_PX=10` 不过
（`completeness.ink_ratio=1.0` 是过的，失败只在最小边）。
另有第二道独立阻碍：首点 56/102/190 → 节距 `46, 88` 不等距，
`pitch_uniform` 也不过。
**要点**：锚点路径有 `content_only` 基（最小边放到 4px，专为 8px 高的真图形，
见 `check_option_crop`），但**无字母版式走不到该基**——这是**规则不对称**，
不是阈值算错。要覆盖它需要一条"无字母带也可按 tight 基判定"的新规则；
而且等距阻碍仍在，需同时决定"非等距版式是否可接受"。**本轮不自行加**。

### C 类 · 裁剪已落盘但证据链为空 —— `ft-grid-10--tight`、`ft-overlay-13--tight`
两页的生产 note 相同：`option_cells_not_label_anchored` +
`stem_evidence_ambiguous_layout`（题干布局假设不唯一 → 整题弃权），
`region_provenance.option_cells` 因此为空，而 `regions*/option_*.png` 已写盘。

* `ft-grid-10--tight`：末带实测 **5 段**（`w24 ink168`、`w12 ink128`、
  `w22 ink168`、`w24 ink168`、`w24 ink168`），题面声明 4 →
  聚类把相邻两段并成一格：`bbox [76,150,62,38] ink **296**`（明显并图）。
  字母层为空（`letter_layers {}`），锚点无从建立；行序谓词在 `cand_n=4`
  因 `pitch/width/ink` 不过（本来就不该过——末带是**混合内容**，页面像素
  里没有"哪 4 段才是选项"的信息）。
* `ft-overlay-13--tight`：末带 **7 段**、墨 32–349 悬殊，`[36..47]` 与
  `[47..68]` 把**同一个** `w33 ink308` 图形劈成 80/227 两格，
  另有一格 `ink **348/349**` 含多图；字母层 `{h=11: 2 个}`（需 4）。
  叠加系列的每格本就含 2–3 个连通域，列聚类无法给出"每格一图"。

**这一类的正确说法**：选项证据**写了盘但没有成为可核对证据**，且其中含
并图/劈图格——不能算"证据完整"，也不能算"0 份选项"。

### D 类 · 对照（证据确实完整）
`ft-rot90-01--tight`（4×168，`cand_n=4` 谓词全过）、
`ft-mirror-04--tight` 扰动件（3×168）与真实截图件（`declared_options=0`，
走行序无字母路径得 3×168）。三页均 `saved == evidence_cells`、零释放。
注：真实 tight 件题面 `declared_options=0`，诊断表里它的
`localizer_at_declared` 用 `n_options=2` 兜底，会把两图并成一格
（`w94 ink336`）——那**不是**生产路径，只作对照，勿据此判断。

## 2. `ink > 250` 只是指路，不是缺陷标记

同一启发式也点了对照页 `ft-overlay-12`（256/320）：那是叠加系列**本来**
每格含多个形状，其单元经**字母锚点**切分并通过同源复核，属正常。
区分依据不是墨量，而是：**是否锚点切分 + 是否与页面真值逐格同源**。
C 类两页的 296/348 格是**聚类并图**（非锚点、未进证据链），与 overlay-12
的 256/320 性质不同。

## 3. 给裁决点 5 的事实小结

| 成因 | 页 | 覆盖它需要的动作 | 风险 |
|---|---|---|---|
| A 尺度序列尺寸悬殊 | scale-09--tight | 放松"宽高/墨一致"正则性 | **高**：该谓词正是防假格阵的门 |
| B 8px 真竖条 + 不等距 | trans-07--tight | 让无字母带也走 tight 内容基（最小边 4px）+ 决定是否容忍非等距 | 中：需新规则，不属调阈值 |
| C 末带混合内容 / 每格多域 | grid-10--tight、overlay-13--tight | 需要"哪几段属于选项"的页面外信息 | **不可安全恢复**（像素里没有该信息） |

现状是三件事同时成立：**零错放**、**A/B 有明确的规则障碍**、
**C 连"选项带是哪几段"都无法从页面像素判定**。是否投入新规则请人工定；
本轮不自行加规则、不动 tol=0.15 / margin_min=0.05 / MIN_CELL_PX=10。
