# 逻辑推理 · 方法笔记

## 第一阶段支持：排序比较模型
- 实体：`meta.logic_entities` 显式指定，或从题干识别天干（甲乙丙…）与独立大写字母。
- 建模：每个实体一个整数分数（1..n，互不相同，分数越大 = 越高/越大/越快）。
- 语句解析：
  - `A比B高/大/长/快/多/早/重` → `A > B`
  - `A比B矮/小/短/慢/少/晚/轻` → `A < B`
  - `A不比B高` / `A没有B高` → `A <= B`
  - `A和B一样高` → `A == B`
  - `A最高` / `A排名第一` → A 大于其余全部
  - `A不是最高` → 存在他人高于 A
- 判定：命题 P “必然为真” ⇔ `约束 ∧ ¬P` 不可满足（Z3）；“可能为真” ⇔ `约束 ∧ P` 可满足。
- 问“谁最高”时按实体唯一性判定；问排序时要求模型唯一。

## 边界（不做的事）
- 不支持真假话（骑士与骗子）、充分必要条件、三段论、图表对应推理。
- 比较属性混杂（既有“高”又有“快”）时视为不同维度，直接失败而不是硬凑。
- 带数值差的比较（“甲比乙高 3 分”）暂不支持，明确报错。
- 选项无法解析为比较命题时失败，不猜测。

## 校验方式
- Verifier 用已解析约束重新建模，重新判定答案选项是否必然成立，并检查是否唯一。

## 常见坑
- 题干中的说明句（“三人参加比赛”）不是约束，需跳过，否则会误判“无法解析”。
- “不是最高”不是“最低”，必须用存在量词编码。
