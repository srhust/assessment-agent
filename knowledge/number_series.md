# 数字推理 · 方法笔记

## 第一阶段支持的规律
| 规律 | 判定 | 优先级 |
| --- | --- | --- |
| 常数 | 所有项相等 | 5 |
| 等差 | 一阶差分恒定 | 10 |
| 等比 | 相邻比值恒定（且 ≠1） | 20 |
| 奇偶分组 | 奇偶位各成规律（等差/等比/二阶差分） | 15 |
| 二阶及以上差分 | k 阶差分恒定，需 ≥ k+3 项防过拟合 | 30+k |
| 递推 | 从第三项起等于前两项之和 | 50 |
| 幂次偏移 | n / n² / n³ / 2ⁿ / 3ⁿ / n! 加常数（允许起始偏移） | 60+shift |

## 求解流程
1. `parse_sequence`：抽取题干数字，忽略末尾 `( )` 空位。
2. `solve_series`：跑全部检测器，只保留能解释**所有**已知项的规律。
3. 优先级最高的规律给出答案；若多条规律给出不同答案，`agreement=False`，置信度下调并列出候选。

## 边界（不做的事）
- 不支持中间缺项（空位不在末尾）——返回 `failed`，明确说明。
- 不支持需要外部语义的规律（如“质数序列”“汉字笔画”）。
- 不强行给唯一解：规律冲突时如实报告歧义。

## 校验方式
- Verifier 做“留出预测”：用前 n-1 项拟合，预测第 n 项是否命中原值；再做全序列复算。

## 常见坑
- 项数太少时高阶差分必然拟合，因此要求 `len ≥ k+3`。
- 小数与分数混用：统一转成 `Fraction` 精确比较。
