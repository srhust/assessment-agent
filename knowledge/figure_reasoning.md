# 图形推理 · 方法笔记（第一阶段已实现）

> 实现位置：`tools/figure_tools.py`（布局与特征）、`tools/figure_rules.py`（规律引擎）、
> `skills/figure_reasoning.py`（技能封装与独立复核）。
> 数据：`data/figure/images/*.png` 由 `scripts/generate_figure_dataset.py` 可复现生成。

## 一、布局约定（决定能否解出）

| 项 | 约定 |
| --- | --- |
| 底图 | 白底黑线/黑块；图形与选项不要重叠 |
| 题干区 | 序列题：一行 3 个已知图形（末格可留空）；九宫格题：3 行 × 3 格 |
| 选项区 | 紧接题干区下方、独立一行，从左到右对应 A、B、C…（2~6 个） |
| 单元格 | 自动推断：行投影切“带”、列投影切“格”，再由格中心间距还原统一网格 |
| 显式网格 | 排列不规则时传 `grid=(行, 列)`：整图按该行列等分，空白格也会被识别 |

自动推断的可靠性取决于“图形大致居中”：同一个格内只有一个居中色块时，墨迹无法反映
格边界，此时位置类规律会被自动禁用（不会瞎套），需要显式 `grid`。

## 二、已实现的规律（必须解释全部已知格，且只匹配一个选项）

| 规律 | 特征 | 适用条件 |
| --- | --- | --- |
| `count` | 连通域个数 | 各格个数构成常数或等差数列 |
| `sides` | 多边形边数（approxPolyDP，ε=0.02·周长） | 每格恰好 1 个封闭多边形，边数 3~12 |
| `fill` | 墨迹像素数 | 面积构成等差数列（同一张图绘制尺度一致） |
| `centroid` | 质心（统一网格内归一化） | 需要可靠网格；步长不能等于格距（那说明图形居中未移动） |
| `symmetry` | 垂直/水平镜像对称（±2px 平移 + 1px 膨胀覆盖率 ≥ 0.82） | 对称性恒定或按奇偶交替 |
| `overlay` | 整格掩码的 异或/并集/交集，IoU ≥ 0.88 判定行规律 | 九宫格；目标格在行末且唯一 |

## 三、实现要点（踩过的坑）

1. **对称性不能用原始 IoU**：3px 细线在栅格化后常有 1px 错位，等腰三角形的垂直镜像
   IoU 只有 0.83，会被误判成不对称。改为“±2px 平移搜索 + 两侧各膨胀 1px 的覆盖率”，
   对称形状稳定到 1.00，斜线仍只有 0.08。
2. **叠加图形会裂成多个连通块**：去同存异后的两枚月牙在列投影上是两段，会被切成两格。
   解决：先按中位间距把每段归到整数列号，同一列的多段合并成一格。
3. **格间距不能取墨迹中心的中位数**：图形大小差异会污染间距估计。改为优先选“间距
   变异系数最小”的那一行（通常是选项行）来估计 pitch。
4. **位置类规律必须有网格**：单个居中色块的墨迹外接框就是它自己，质心永远在 0.5。
   因此 `centroid` 只在统一网格（自动推断为规则网格或显式 `grid`）下启用。

## 四、尚未实现（调用会明确失败，不给结论）

- 旋转/翻转匹配（`rotation_match`）：需要角度不变特征与顶点对应。
- 曲线图形/立体阴影分类（`curved_shape_classification`、`shadow_3d_features`）。
- 非叠加类九宫格规律（位置轮换、样式交替、行列和差）。
- 多规律冲突时的仲裁策略：目前直接失败并列出每条规律的结论。
- 手绘/低分辨率截图：二值化与投影对噪声敏感，需先去噪与自适应阈值。

## 五、失败与复核策略

- 每条规律都必须在**全部已知格**上成立，否则不作为候选；
- 只与**唯一一个选项**匹配才算候选，命中多个即视为歧义；
- 多条候选规律给出不同答案 → 直接失败（不按优先级硬凑）；
- 校验环节换一个二值化阈值（Otsu ↔ 127）独立复算，答案不一致则拒绝接受。
