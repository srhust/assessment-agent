# 图形推理 · 方法笔记（第二阶段）

> 状态：`tools/figure_tools.py` 已提供**真实可用**的基础观测（尺寸、墨迹占比、
> 九宫格切分）；规律识别（`detect_shapes` / `match_transform` / `grid_rule_inference`
> / `symmetry_score` / `overlay_compare`）尚未实现，调用会抛 `NotImplementedError`。

## 常见规律维度
- 数量：边数、交点数、封闭区域数、笔画数、点线面元素个数
- 位置：平移（步长、方向）、旋转（角度、顺时针/逆时针）、翻转（水平/垂直）
- 样式：叠加（去同存异、去异存同）、黑白互换、阴影变化
- 属性：对称性（轴对称/中心对称）、曲直性、开闭性
- 结构：图形分组、九宫格行/列/对角线规律、折叠展开对应关系

## 第二阶段实现路径
1. 图像预处理：二值化、去噪、裁剪到单元格（已有 `grid_ink_density` 打底）。
2. 特征提取：轮廓 → 多边形逼近 → 边数/顶点/面积/重心/对称轴。
3. 规律假设生成与检验：对每个候选规律在已知格上验证，全部通过才外推。
4. 选项比对：把选项图按同一特征向量比对，输出带证据的答案。

## 硬性要求
- 特征提取失败或规律不唯一时，明确返回失败/歧义，不猜。
