## 指标与公式
| 指标 | 公式 |
| --- | --- |
| 增长率 | (本期 − 基期) / 基期 |
| 增长量 | 本期 − 基期 |
| 年均增长率 | (末期/初期)^(1/年数) − 1 |
| 比重 | 部分 / 整体 |
| 比重变化 | 现期比重 − 基期比重，单位是**百分点** |
| 平均数 | 总量 / 份数 |
| 倍数 | A / B（注意“是几倍”与“多几倍”差 1） |

## 解题方法论
1. 先读问题定位指标与时间范围，再回表找数（避免被干扰列带走）。
2. 估算优先：选项差距大时用截位直除，差距小时保留 3~4 位有效数字。
3. 单位与量级校验：万/亿、百分数 vs 百分点、人 vs 人次。
4. 计算结果必须与选项量级一致，否则回查公式或取数。
