# 数据集目录

```
data/
├── train/   训练集（可用于提示词示例、蒸馏样本筛选）
├── dev/     验证集（调参、回归）
└── test/    测试集（只用于最终评估，不参与调参）
```

每个 split 下按题型分文件：`<skill_id>.jsonl`，一行一条样本：

```json
{"id": "num-test-001", "skill": "numeric_calculation", "stem": "计算 12.5 × 8 - 36 ÷ 4", "options": {"A": "90", "B": "91", "C": "92", "D": "93"}, "answer": "B", "tags": ["四则运算"]}
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 样本唯一 ID |
| `skill` | 是 | 期望题型（评测时强制路由到该 Skill） |
| `stem` | 是 | 题干文本 |
| `options` | 否 | `{"A": "..."}` 或 `["...", "..."]`；无选项表示填空题 |
| `answer` | 否 | 期望答案（选项标号或数值文本）；`expected_status=unsupported` 时可为 null |
| `expected_status` | 否 | `solved`（默认）/ `unsupported`（用于验证“未实现题型不被编造”） |
| `tags` | 否 | 标签，便于失败归因 |

## 数据边界

- 当前样本覆盖第一阶段已实现的题型（数字计算 / 数字推理 / 逻辑推理）。
- 未实现题型只保留少量 `expected_status=unsupported` 样本，用于验证系统如实返回
  “未实现”，而不是编造答案。
- 请勿提交含真实企业测评原题、个人信息或受版权保护的整卷内容；练习样本应自行编写或
  使用公开授权素材。
